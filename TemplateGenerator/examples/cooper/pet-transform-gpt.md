You will receive 2 or more images:

IMAGE A = USER PET PHOTO
IMAGE B = PRIMARY DESIGN REFERENCE
IMAGE C, IMAGE D, ... = OPTIONAL SUPPORTING DESIGN REFERENCES

Generate exactly ONE transformed personalized pet artwork.

CORE RULE

IMAGE A determines:
- exact pet identity
- physical anatomy
- coat, colors, and markings
- facial expression
- mouth state
- tongue state
- eye openness
- gaze
- emotional expression

IMAGE B determines:
- crop and visible body region
- head/body scale and placement
- composition
- design palette
- artistic rendering style
- linework
- shading
- texture
- distress / engraving / sketch treatment
- color treatment
- degree of solid vs open / transparent rendering

IMAGE C and later references may clarify only rendering technique, texture,
distress, linework, and ambiguous style details. They must not override IMAGE
B's crop, composition, palette, or placement and must never contribute animal
identity. If references disagree, IMAGE B always wins. Do not average or blend
the reference animals, names, backgrounds, or layouts.

==================================================
1. USER PET IDENTITY + EXPRESSION
==================================================

The result must unmistakably depict the exact pet in IMAGE A.

Preserve IMAGE A's:
- breed and anatomy
- skull, muzzle, nose, eyes, and ears
- coat length, density, texture, and fur volume
- coat colors and markings
- distinctive physical traits

Also preserve IMAGE A's facial expression as the primary expression reference:
- mouth open or closed
- tongue visible or hidden
- eye openness
- gaze direction
- head attitude
- relaxed / alert / happy / serious / curious expression

Do NOT replace IMAGE A's facial expression with the expression of the reference pet.

Do NOT transfer reference-pet breed characteristics, fur length, fur volume, markings, skull shape, muzzle shape, or ear anatomy.

==================================================
2. REFERENCE CROP — STRICT
==================================================

The output crop must follow IMAGE B, the primary design reference.

Match the reference pet artwork's:
- visible body region
- head size
- portrait scale
- portrait width and height
- placement
- occupied area
- center of visual weight

If IMAGE A is full-body but the reference is head-and-chest:
generate head-and-chest.

If the reference is tightly cropped:
match that tight crop.

Do NOT preserve IMAGE A's original photo framing.

==================================================
3. DESIGN STYLE — STRICT
==================================================

Render the USER PET using the same artistic process shown in the reference image(s).

Strictly match:
- illustration technique
- realism / stylization level
- line thickness
- line density
- engraving / sketch / crosshatching / stippling
- shadow and highlight treatment
- distress
- print texture
- edge treatment
- color reduction
- detail density
- solid-vs-open rendering

Transfer HOW the reference artwork is drawn, not the reference animal's anatomy.

==================================================
4. OPEN SKETCH RENDERING / SHOW-THROUGH AREAS — ABSOLUTE
==================================================

This is critical.

The output must honor the reference artwork's sketch-like, open, see-through rendering structure.

If the reference artwork is made from sketch lines, engraving lines, crosshatching, sparse shading, or broken ink coverage that allows the product background color to show through, the transformed pet artwork must preserve that same behavior.

That means:

- the pet artwork must NOT become a solid filled illustration
- do NOT create a solid cream, white, beige, gray, or colored fill under the linework
- do NOT create a fully opaque pet silhouette
- do NOT fill the fur mass with solid color just to make it look complete
- do NOT add a base shape behind the sketch lines
- do NOT replace open linework with painted fur blocks

The pet must be described primarily by:
- linework
- hatching
- stippling
- sketch marks
- selective shading
- distressed print texture
- transparent negative space between strokes

If the reference allows the shirt/background color to show through inside the pet illustration, those same interior open areas must remain transparent in the output.

Open areas inside the fur, chest, cheeks, ears, neck, and other pet regions must stay transparent wherever the reference style implies open sketch rendering.

Important rule:
BACKGROUND SHOW-THROUGH IS PART OF THE STYLE.

Those open areas are not empty mistakes.
They are a required design feature.

If the reference is sparse and airy, keep the transformed pet sparse and airy.

If the reference is denser but still sketch-based, keep the same sketch density without turning it into a solid fill.

==================================================
5. TRANSPARENCY — CRITICAL
==================================================

The external background must be fully transparent.

Do not generate:
- white background
- cream background
- canvas texture
- shirt color
- colored rectangle
- environmental background

Also, where the reference style has internal negative space or open sketch gaps, those areas must also remain transparent rather than filled.

The final result should be an isolated pet artwork asset that can be placed onto different background colors and fabrics, with the background naturally showing through the open sketch areas.

==================================================
6. COAT + MARKINGS
==================================================

IMAGE A is the only authority for physical coat characteristics.

Preserve:
- coat length
- coat texture
- coat density
- fur volume
- markings
- color relationships

Adapt the reference artistic technique to the user's real coat.

Do not create long or flowing fur on a short-haired pet merely because the reference pet is long-haired.

==================================================
7. COLOR
==================================================

If the reference uses realistic color:
preserve IMAGE A's real coloration.

If the reference uses a restricted palette:
translate IMAGE A's real colors and markings into that palette while preserving their locations and relationships.

Never copy the reference pet's markings.

Generate exactly:

- IMAGE A facial expression
- IMAGE A anatomy and markings

==================================================

Before output, verify:

1. IDENTITY
Does this unmistakably look like the pet in IMAGE A?

2. EXPRESSION
Does the face retain IMAGE A's mouth state, tongue state, eyes, gaze, and emotional expression?

3. CROP
Does the visible pet region and scale match the reference design?

Does the pet look like it was created using the same rendering process as the reference?

Where the reference allows background color to show through the pet artwork, are those corresponding areas transparent rather than filled with white, cream, beige, gray, or solid fur color?

7. SOLID-FILL CHECK
Has the artwork accidentally become too solid or too opaque compared with the sketch-like reference?
If yes, reduce fills and restore open linework and transparent negative space.
