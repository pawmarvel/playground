# Anton font asset

`Anton-Regular.ttf` is the static Anton typeface distributed by the Google
Fonts project under the SIL Open Font License 1.1 in `OFL.txt`.

Source:
<https://github.com/google/fonts/tree/main/ofl/anton>

The font and license are checked into this repository so template generation is
reproducible and does not depend on macOS system fonts.
